# PULSE — Plataforma para Personal Trainers

Versão publicada: **5.2.2 (protótipo demonstrativo)**

Plataforma visual de gestão para personal trainers, alunos e administração, incluindo módulos demonstrativos de treinos, biblioteca de exercícios, agenda, avaliações e cobranças.

## Visualizar

O aplicativo completo de demonstração está em [index.html](./index.html). Para uma prévia pública no navegador, habilite GitHub Pages em **Settings → Pages → Deploy from a branch**, selecionando **main** e **/(root)**.

## Importante

- O aplicativo é um **protótipo**: login, dados de usuários e operações são simulados.
- **Não** cadastrar alunos reais, avaliações físicas ou dados pessoais sensíveis.
- O Supabase específico do PULSE ainda não foi identificado/conectado.
- Este repositório é independente do projeto NEXO IA.
- O repositório está **público** no GitHub, conforme configuração atual.

## Desenvolvimento

O projeto original, com arquivos HTML/CSS/JavaScript separados e imagens, está disponível no pacote **PULSE v5.2.2 — PRONTO GITHUB**, compartilhado na conversa. O arquivo `index.html` desta publicação contém a versão de demonstração autônoma, com o código e as imagens incorporados.
